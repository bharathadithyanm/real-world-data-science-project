# 📊 Real-World Retail Data Project

## 📌 Project Overview
This project performs real-world retail sales analysis using Python and Machine Learning.

The project includes:
- Data Analysis
- Data Visualization
- Sales Prediction
- Interactive Dashboard

---

## 📁 Project Structure

```bash
real_world_data_project/
│
├── data/
│   └── retail_sales.csv
│
├── notebooks/
│
├── outputs/
│   ├── charts/
│   └── models/
│
├── analysis.py
├── app.py
├── requirements.txt
└── README.md
```

---

## 🚀 Features

- Analyze retail sales data
- Visualize category-wise sales
- Predict future sales using Linear Regression
- Streamlit dashboard for interactive insights

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Plotly

---

## ▶️ Run the Project

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Analysis

```bash
python analysis.py
```

### Run Streamlit Dashboard

```bash
streamlit run app.py
```
